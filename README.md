# Hotel Management System

A C++ Object-Oriented Programming project developed during my second semester at Air University.

## Overview

This project simulates a hotel management system and was built to practice Object-Oriented Programming concepts.

## OOP Concepts Used

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Virtual Functions
* File Handling
* STL Vectors

## Purpose

The goal of this project was to strengthen my understanding of software design and object-oriented programming principles through a practical application.

## Technologies

* C++
* Object-Oriented Programming
